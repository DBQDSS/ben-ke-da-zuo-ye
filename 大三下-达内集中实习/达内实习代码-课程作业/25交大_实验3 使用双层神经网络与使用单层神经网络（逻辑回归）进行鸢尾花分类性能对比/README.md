A:

我对单层神经网络(Logistic)和双层神经网络在鸢尾花数据集上的表现进行了比较，固定以下条件：

1. 训练轮数 (epochs)：1000
2. 优化器：Adam
3. 测试集占比：20%
4. 数据预处理：特征标准化

调整的超参数：
1. 单层网络(Logistic)：学习率 = 0.01
2. 双层网络：学习率 = 0.001（隐藏层维度 = 8，激活函数 = ReLU）

实验过程中我进行了如下思考：

1. 尽管模型复杂度不同，但在鸢尾花数据集上，单层和双层网络最终达到了几乎相同的分类准确率。这主要是因为：
   1. 鸢尾花数据集本身复杂度较低（仅 4 个特征，150 个样本，3 个类别线性可分性较好） 
   2. 标准化预处理消除了特征尺度差异，减轻了模型学习负担。
   3. 分类边界相对简单，单层线性模型已能较好拟合。
2. 学习率的设置会对模型训练产生影响，双层网络需要更小的学习率才能稳定收敛。
3. 收敛速度差异：
   1. 单层网络收敛更快，因为线性模型参数空间结构简单，优化目标明确
   2. 双层网络需更长时间调整隐藏层权重以提取有效特征表示
4. 泛化能力对比
   1. 测试集上两者表现相当，但双层网络理论上具有更强泛化潜力：
   2. 双层网络通过引入非线性变换，能学习更复杂的决策边界
   3. 在更复杂数据集上，双层网络可能会展现出其优势
