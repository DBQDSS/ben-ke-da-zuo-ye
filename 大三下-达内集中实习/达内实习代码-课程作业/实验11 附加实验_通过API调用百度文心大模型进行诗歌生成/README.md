### WenXinAI.py

模型输出：AI写的诗词

### 问题回答
#### Q：

1. 实验目的
  - 掌握如何通过API调用百度文心大模型进行文本生成任务。
  - 了解文心大模型在自然语言生成（NLG）中的应用。
  - 学习如何设置API请求参数以控制生成文本的风格和结构。 
  - 提升对文本生成技术的理解，体验生成式AI模型在创意写作中的实际应用。

2. 实验平台
 - 开发环境: Jupyter Notebook或其他Python集成开发环境（IDE）。 
 - 编程语言: Python 3.x。 
 - 工具包: NumPy, PaddlePaddle, paddlenlp, matplotlib等。

3. 实验内容和要求
通过调用百度文心大模型的API，完成中文诗歌生成任务。实验内容包括：申请并配置API密钥，编写Python程序通过HTTP请求调用文心大模型的文本生成接口，设置诗歌生成相关参数(如主题、生成长度、温度(temprature)等)，实现诗歌自动生成，并解析和展示生成结果。通过调整不同参数，观察生成效果的差异，掌握大模型在自然语言生成任务中的基本使用方法。

要求：
1. 给出实验结果并对结果进行分析与讨论(在答案框中填写)。
2. 本作业为附加题，不计入最终成绩。如在核算成绩前提交(时间另行通知)，则实训项目成绩另加1分(实训项目成绩最高计100分，占总评成绩的60%)。

#### A：

1. 主题：设定行文方向
2. 情感基调：负向→愁绪，正向→喜乐
3. 风格：浪漫造意境，现实写实景，哲理藏思考
4. 体裁：限定格式  
5. 温度：高→创意新颖，低→表达保守
6. 长度：控制篇幅

参数组合直接调控诗歌的 **情绪、形式、创意度**，实现“定向生成”。
